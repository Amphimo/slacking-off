# 摸鱼小窗

一个 Windows 桌面小窗，用来以接近手机端的形态刷抖音 / B站 / 小黑盒 / 小红书。

> 这是一个非官方个人工具，只用于学习和自用。平台接口、页面结构和风控策略随时可能变化，功能可能突然失效。

## 当前设计

- 主窗口是一个无边框 Electron 小窗，支持站点切换、视口缩放、窗口置顶、透明度和老板键隐藏。
- 抖音、B站、小黑盒使用本地自绘面板；小红书使用网页版窄屏响应式。
- 各站点登录态保存在本机独立数据目录，不上传，也不收集账号信息。
- 对需要登录态或平台校验的接口只做必要适配；不识别验证码，不绕过风控，不做批量操作。
- 遇到抖音人机验证时，只打开官方验证页面，由用户本人完成后再继续。

## 风险说明

- 本项目不是抖音、B站、小红书或小黑盒官方客户端，与各平台无关联。
- 使用本项目可能不符合部分平台的服务条款；点赞、收藏、评论等账号操作由使用者自行承担风险。
- 平台接口随时可能变动，某些站点或功能可能失效。
- Windows 程序未购买代码签名证书，首次运行可能触发 SmartScreen；少数杀毒软件也可能误报。
- 登录 Cookie 只保存在本机 `%APPDATA%\slacking-off`。分享安装包或源码不会带上你的账号数据。
- 所有内容版权归原平台及作者所有。

## 下载

到仓库的 **Releases** 页下载：

- `slacking-off-<版本>-win-x64.zip`：免安装版，解压后运行 `slacking-off.exe`。
- `slacking-off-<版本>-win-x64-setup.exe`：安装版，会创建桌面和开始菜单快捷方式。

目前只提供 Windows 10 / 11 x64 构建。

## 开发

```bash
npm install
npm start
npm run dist
```

`npm run dist` 会生成免安装 zip 和 NSIS 安装包。
